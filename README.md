# 镜头扫描分析台

这是一个可离线运行的网页工具，用来上传视频或输入链接，生成逐镜头画面描述、扫描镜头标注和镜头语言分析。

## 在本机打开

1. 安装 Node.js：https://nodejs.org/
2. 双击 `start-windows.bat`
3. 在浏览器打开 `http://127.0.0.1:5177`

## 让同一 Wi-Fi 的别的电脑打开

1. 在运行网站的电脑上双击 `start-windows.bat`
2. 查看这台电脑的局域网 IP，例如 `192.168.0.123`
3. 别的电脑打开 `http://这台电脑的IP:5177`

示例：

```text
http://192.168.0.123:5177
```

如果打不开，请在 Windows 防火墙里允许 Node.js 通过“专用网络”。

## 当前能力

- 本地视频上传和预览
- 最多 30 段自动扫描
- 约 10 秒一段生成镜头段落
- 标注扫描镜头、摇镜头、跟拍、推镜头、景别
- 编辑画面描述
- 导出 Markdown 分析稿

## 注意

当前版本是本地网页工具，输入链接时会生成分析稿框架；如果要真正自动读取互联网视频链接并识别画面，需要额外接入视频下载/抽帧和 AI 视觉分析服务。
